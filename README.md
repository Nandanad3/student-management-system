# Student Management System

## Project Description

The Student Management System is a collaborative project developed using Git and GitHub.

## Modules

- Login
- Dashboard
- Student Management
- Reports
- User Interface

## Git Workflow

Each team member works on a separate feature branch.
Completed features are committed and pushed to GitHub before being merged into the main branch.

## Team Structure

| Member | Responsibility |
|---|---|
| Member 1 | Login & Repository Setup |
| Member 2 | Dashboard |
| Member 3 | Student Management |
| Member 4 | Reports |
| Member 5 | UI & Testing |
